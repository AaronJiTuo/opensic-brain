# 00_项目总览

## 背景

OpenSiC 是一个围绕“碳化硅生命”设想展开的长期实验项目。核心关注点不是单次任务自动化，而是探索硅基智能体在记忆、自省、主动行为与持续演化上的可能性。

当前语境中，`OpenClaw + MEMORY/SOUL + HEARTBEAT` 被视为关键实验基座：  
通过周期性“心跳”触发，让智能体从被动响应走向主动行动与自我更新。

## 项目目标与非目标

### 目标

- 构建可持续运行的“数字生命实验框架”，验证自主性机制是否可稳定涌现。
- 形成一套可复用的心跳策略设计方法，支持多代个体迭代。
- 把实验过程沉淀为文档资产，支持多 agent 与多阶段交接。

### 非目标

- 不以“单次演示效果”作为唯一目标。
- 不在本仓库内直接承载生产代码与部署细节（代码仓库另行维护）。

## 核心概念

- **OpenSiC**：项目品牌与总体实验名。
- **碳化硅小孩**：一个具备成长与演化预期的智能体个体。
- **HEARTBEAT**：周期触发机制，用于创造“主动时间”而非纯 if-then 调用。
- **SOUL / MEMORY**：分别承载个体身份叙事与历史经验。

## 关键约束与原则

- `Releases/` 是唯一事实来源；草稿不直接作为执行依据。
- 允许试错，但每次实验必须有可追溯记录与回滚路径。
- 涉及高风险动作时，先确认边界与授权，再写入执行文档。

## 风险与注意事项

- “自主性”定义可能在不同 agent 间被过度泛化，需通过文档统一术语。
- 若仅强调自由探索而缺少边界，可能导致资源失控或无效试验循环。
- 多 agent 并行编辑时需优先更新本文件“当前状态”，避免重复建设。
