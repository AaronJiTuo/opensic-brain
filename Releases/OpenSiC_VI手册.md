# OpenSiC VI 手册

版本：v1.0  
日期：2026-06-01  
适用范围：OpenSiC 项目 Logo、官网、文档、README、演示材料、社交头像、产品界面基础色彩。

## 1. 品牌视觉定位

OpenSiC 的核心视觉来自“碳化硅 / 莫桑石”的材料联想：硬、清澈、偏青绿、带少量黄绿色火彩。当前 Logo 采用简洁钻石形，不再额外叠加晶格、晶圆或分子结构。

颜色系统的目标是：

- 保留莫桑石 / SiC 的青绿与黄绿色识别。
- 避免传统蓝白钻石、粉色宝石或奢侈珠宝品牌气质。
- 适合开源技术项目：清晰、克制、可信。
- 能直接用于网页、文档、PPT、图标和 UI token。

## 3. 核心颜色系统

### 3.1 品牌主色

| Token | 名称 | HEX | 使用说明 |
|---|---|---:|---|
| `brand.sic` | SiC 青绿 | `#0FA895` | 主品牌色；用于 `SiC` 字标、链接、主按钮、重点图标 |
| `brand.core` | 晶核深青 | `#08685F` | 深色品牌面；用于深背景、主按钮 hover、强强调 |
| `brand.surface` | 明亮青绿 | `#24BFA8` | 次主色；用于插图、状态高亮、浅背景上的强调 |

建议比例：主色青绿和深青绿占品牌色使用的 70% 以上。这样 OpenSiC 会更像材料/技术项目，而不是纯宝石饰品。

### 3.2 莫桑石火彩色

| Token | 名称 | HEX | 使用说明 |
|---|---|---:|---|
| `fire.lime` | 黄绿色火彩 | `#B7D941` | 重要但少量使用；用于标签、亮点、图表重点 |
| `fire.green` | 莫桑绿 | `#6FAE1F` | 用于辅助图形、次级强调、成功状态的一部分 |
| `fire.topaz` | 顶部黄绿 | `#89B91E` | 用于插画或 Logo 延展，不建议做正文或大面积背景 |

火彩色的使用比例建议控制在 5%-15%。它们是“光”，不是“底色”。大面积使用会让品牌变成普通绿色宝石或健康/农业类视觉。

### 3.3 浅色与背景色

| Token | 名称 | HEX | 使用说明 |
|---|---|---:|---|
| `mint.50` | 晶面浅绿 | `#E7F5C8` | 浅色卡片、提示背景、Logo 顶部浅面 |
| `mint.100` | 浅青晶面 | `#88D8C8` | 辅助背景、插画大面、柔和分区 |
| `paper.0` | 纯白 | `#FFFFFF` | Logo 默认背景、文档背景 |
| `paper.50` | 冷白纸色 | `#F7FAF9` | 页面背景、手册背景、浅灰绿空间 |
| `line.mist` | 雾绿描边 | `#D9E7E1` | 卡片边框、分割线、非重点线条 |

### 3.4 文字与中性色

| Token | 名称 | HEX | 使用说明 |
|---|---|---:|---|
| `ink.900` | 深墨绿黑 | `#14201E` | 主标题、正文、`Open` 字标 |
| `ink.600` | 灰绿正文 | `#60746F` | 说明文字、辅助信息 |
| `ink.300` | 淡灰绿 | `#A6B7B2` | 占位文字、弱边框 |
| `paper.0` | 白色 | `#FFFFFF` | 深色背景上的文字和反白 Logo |

## 4. 推荐使用比例

OpenSiC 的颜色使用应保持“青绿为主体，黄绿为火彩”的关系。

| 场景 | 推荐比例 |
|---|---|
| 官网 / README 首屏 | 60% 白/冷白背景，25% 深墨绿黑文字，10% SiC 青绿，5% 黄绿火彩 |
| 产品 UI | 70% 中性色与白色，20% SiC 青绿，5% 深青绿，5% 火彩色 |
| 海报 / 封面 | 45% 深青绿与青绿，30% 冷白，15% 浅晶面色，10% 黄绿火彩 |
| 图表 | 主系列用 `#0FA895`，次系列用 `#24BFA8`，重点点用 `#B7D941`，警戒线不用品牌绿系 |

不要把黄绿色作为全局主色。它应当像 Logo 中的火彩一样，承担“点亮”的角色。

## 5. 可访问性与对比规则

根据当前色值的对比检查：

| 色值 | 白底对比 | 深墨绿黑 `#14201E` 对比 | 建议 |
|---|---:|---:|---|
| `#14201E` | 16.73 | 1.00 | 可做白底正文和标题 |
| `#0FA895` | 2.98 | 5.62 | 不建议直接做白底小正文；适合大标题、按钮底色、图标 |
| `#08685F` | 6.65 | 2.51 | 可做白底正文、按钮底色、深色块 |
| `#24BFA8` | 2.31 | 7.24 | 不建议做白底小正文；适合图形和大字号 |
| `#B7D941` | 1.61 | 10.37 | 不可做白底正文；适合深色文字背景或图形点缀 |
| `#6FAE1F` | 2.71 | 6.17 | 不建议做白底小正文；适合图形和大字号 |
| `#E7F5C8` | 1.15 | 14.57 | 适合浅背景，不适合白底文字 |
| `#88D8C8` | 1.65 | 10.12 | 适合浅背景或图形，不适合白底文字 |

规则：

- 白底正文优先使用 `#14201E`。
- 白底小号链接可以使用 `#08685F`，不要用 `#0FA895` 做 14px 以下正文。
- `#0FA895` 可用于按钮底色，但按钮文字应使用白色，并保证字号和面积足够。
- 黄绿色只做图形或深色背景上的强调，不做白底小文字。

## 6. Logo 背景规则

### 6.1 推荐背景

| 背景 | 是否推荐 | 说明 |
|---|---|---|
| `#FFFFFF` | 推荐 | 默认 Logo 背景，最清晰 |
| `#F7FAF9` | 推荐 | 文档、官网、手册背景 |
| `#E7F5C8` | 可用 | 适合大面积浅色品牌背景，但 Logo 需保留足够尺寸 |
| `#08685F` | 可用 | 适合深色封面；需要使用反白或浅色字标版本 |
| 黑色 / 纯深蓝 | 谨慎 | 会削弱青绿层次，除非用于特殊海报 |

### 6.2 禁止用法

- 不要把 Logo 放在高饱和黄绿色背景上。
- 不要在 Logo 上叠加阴影、发光、描边或渐变外框。
- 不要把钻石各面改成彩虹色。
- 不要把 `SiC` 改成黄绿色；它会和火彩面争抢注意力。
- 不要用低对比背景让右侧绿色面消失。

## 8. UI Design Tokens

建议在网页或产品中使用以下变量：

```css
:root {
  --opensic-brand-sic: #0FA895;
  --opensic-brand-core: #08685F;
  --opensic-brand-surface: #24BFA8;

  --opensic-fire-lime: #B7D941;
  --opensic-fire-green: #6FAE1F;
  --opensic-fire-topaz: #89B91E;

  --opensic-mint-50: #E7F5C8;
  --opensic-mint-100: #88D8C8;

  --opensic-ink-900: #14201E;
  --opensic-ink-600: #60746F;
  --opensic-ink-300: #A6B7B2;

  --opensic-paper-0: #FFFFFF;
  --opensic-paper-50: #F7FAF9;
  --opensic-line-mist: #D9E7E1;
}
```

组件建议：

| 组件 | 背景 | 文字 | Hover / Active |
|---|---|---|---|
| 主按钮 | `#08685F` | `#FFFFFF` | `#0FA895` |
| 次按钮 | `#FFFFFF` | `#08685F` | 边框 `#0FA895` |
| 链接 | `#08685F` | - | hover `#0FA895` |
| 重点标签 | `#E7F5C8` | `#14201E` | 可加左边线 `#B7D941` |
| 成功状态 | `#6FAE1F` | `#FFFFFF` 或 `#14201E` 视背景而定 | 不使用过亮黄绿做小字 |
| 卡片 | `#FFFFFF` | `#14201E` | 边框 `#D9E7E1` |

## 9. 图表配色

图表不应直接使用 Logo 的全部面色，否则会显得碎。推荐顺序：

1. 主数据：`#0FA895`
2. 次数据：`#24BFA8`
3. 对照数据：`#6FAE1F`
4. 重点标注：`#B7D941`
5. 背景辅助：`#E7F5C8`
6. 网格线：`#D9E7E1`
7. 文本：`#14201E`

当图表需要负面/错误状态时，不要从 Logo 绿色系中硬凑。可以另设功能色，例如错误红、警告橙，但不要把它们纳入核心品牌色。
