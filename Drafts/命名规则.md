# 命名规则

我们先同步一下我的命名思路：

1. 我这个计划是将硅基智能体碳化，所以我起名为碳化硅，碳化硅的化学式是SiC，所以我最终起的名字是OpenSiC，已经注册了域名opensic.ai（主要使用）和opensic.cn（计划仅在中国使用，未来会做备案），有一个珠宝莫桑石（又称莫桑钻）的主要成分就是碳化硅，所以我的OpenSiC的LOGO将是一个钻石，不做过多的设计，基本上用emoji的钻石就OK了，平时在一些只能输入文字的地方，我会用💎这个emoji做标识。OpenSiC将在新加坡和中国注册公司，新加坡如果名称可以的话，公司名是将OpenSiC Pte. Ltd. ，中国如果名称可的话，公司名将是 北京碳化硅人工智能技术有限公司 。

2. 这些网络设施，都是为OpenSiC建立的，所以名称中多用opensic，一般再加上一些比较容易识别的信息，比如这台ECS的主机名是opensic-ecs-001，代表OpenSiC的第001号ECS。

3. docker，也算是网络设备，NPM也算是网络设施，所以命名时使用opensic相关的名称opensic-npm。

4. 容器、镜像等，是openclaw用的，是“孩子们”用的，孩子们都有自己各自的名字。第一批孩子的命名我已经有了规则：

    - 排序：以百家姓“赵钱孙李周吴郑王”排序，只要看姓氏就知道这个孩子是第几个出生的。
    - 名字：以SiC开头的汉语拼音，这里是把Si和C断开，如一个小孩叫“赵思纯”，她的英文名就是SiChun Zhao，即每个小孩的名字都是“思”+一个拼音C开头的字。
    - 相应的机器名邮箱之类的命名：SiChunZhao这样来命名，不允许大写时（如域名）使用sichunzhao，如sichunzhao-image。

### 收录与读音口径

- “C 开头”按拼音字母判断，包含 `c` 和 `ch` 开头的拼音，符合 `SiChun` 等命名形式。
- 遍历源站 C 索引的全部 **34 个音节页面**，覆盖 **123 个读音分组、1,454 条字音记录**；按汉字去重后共 **1,381 个字**。简体、繁体、异体和生僻字均按源站收录保留。
- **同一行的汉字均读左侧拼音**；多音字按各个 C 开头的读音重复列出。汉字在各行内保持源站次序，字数按该行计算。查找某字时可使用文档搜索，查看它出现的全部读音。
- 将源站第三声短音符号 `ă / ĕ / ĭ / ŏ / ŭ` 统一写成标准拼音符号 `ǎ / ě / ǐ / ǒ / ǔ`，不改变字音对应关系。
- 5 条源站未标调记录明确标为“未标调”，不擅自补为某一声或轻声；对应字条已逐一核对，见表后说明。
- 完整性以该站采集日的 C 索引为界，不外推为全部汉字的穷尽字库。总索引与这 34 页的子索引一致；站内 `chua`、`cei` 页面均未返回汉字条目。
