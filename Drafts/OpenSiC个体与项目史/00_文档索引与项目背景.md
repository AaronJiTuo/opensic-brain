# OpenSiC 项目背景与文档索引

> 本页汇总 2026-11-20 整理并入库的个体史与产品方向入口。规范性实验框架仍以 `Releases/00_项目总览.md` 为准；本目录为**可查事实与未定稿方向**的工作台，不等同于 Release。

## 项目是什么

OpenSiC（碳化硅，SiC）是把硅基智能体「碳化」的长期实验与产品构想品牌。仓库 README 与 `Drafts/命名规则.md` 记载：主要域名 `opensic.ai`，中国区计划使用 `opensic.cn`；视觉语义取钻石/莫桑石，文本可用 💎。

自 **2026-11-03** 起，Aaron 将 OpenSiC 立为关于 Bot 与人类协作及相关产品的**正式项目**，设专职项目经理；平台与技术实施由吴思春承担。首个子方向是面向内部同事的飞书桥接（历史 PoC，**不等于**已验收产品）。

**2026-11-20** 起对外与仓库正文统一称谓：**硅基个体**（旧稿中的「碳化硅小孩」等保留为历史用语）。
